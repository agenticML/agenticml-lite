# Package 29.5b: On-prem server and Hosted service names on the docs site

Nov 15, 2026 · supervisor plan · coder: Sonnet

## Goal

The owner asked on the docs site design board (comment on the Home
artboard, Nov 15, 2026) to make every tile under **Three ways to use it**
and **Why agenticml-lite** open its page, like the **Start here** tiles.
That part landed on `dev` first, in
[#67](https://github.com/agenticML/agenticml-lite/pull/67) (every tile is a
`LinkCard`), so this package keeps #67's links and does not touch them.

While checking the page locally (Nov 15, 2026), the owner found "Self-hosted"
and "Hosted" too alike. The self-hosted way should read as an on-prem
install, and the hosted one as a managed service that runs the server for
you. This package renames them on the Home tiles and in the sidebar.

## Files to touch

- `website/src/content/docs/index.mdx`: two `LinkCard`s in the "Three ways
  to use it" grid.
- `website/astro.config.mjs`: the sidebar label of the `server` group.
- `docs/plans/on-prem-roadmap.md`: a 29.5b row under 29.5.

Nothing else. No CSS, no components, no other page.

## Approach

1. In the "Three ways to use it" grid, keep each `href`:
   - "Self-hosted" becomes **On-prem server**, description: "Run the 3.0
     server on your own hardware, inside your network, for a shared
     dashboard and sync."
   - "Hosted (public preview)" becomes **Hosted service (public preview)**,
     matching the sidebar's "Hosted service" label, description: "We run
     the server for you. Sign in at app.agenticml.xyz and sync your runs.
     Best effort, no SLA."
2. In `website/astro.config.mjs`, the sidebar group `label: 'Server'`
   becomes `label: 'On-prem server'` (owner's follow-up, Nov 15, 2026). It
   is the only place the label is set.

## Constraints and conventions

- Do not name other products in the descriptions.
- The `server/` URLs, the page titles ("Server overview"), the hero, the
  other tiles, and the "self-hosted" wording in other pages stay as they
  are.
- Same markup style as the rest of the page (tabs, one `LinkCard` per line).

## Edge cases

- The description strings must not contain a double quote.
- Links elsewhere point at `/agenticml-lite/server/...`, which does not
  change, so no link breaks.

## Tests and checks

- `testbed/.venv/bin/python -m pytest -q tests/test_website_facts.py` from
  the repo root.
- In `website/` with Node 22: `npm run build` (runs the links validator) and
  `npm run check:overflow` (375px, no sideways scroll).
- Look at the Home page and the sidebar on the local dev server.

## Done when

The two tiles and the sidebar section show the new names, the page builds
with no link errors, the overflow check and the facts tests pass, and the
29.5b roadmap row says `in review`.
