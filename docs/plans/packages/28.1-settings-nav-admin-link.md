# Package 28.1: one Admin entry (drop "Server admin ↗" from the Settings nav)

Nov 14, 2026 · supervisor plan · coder: supervisor

## Goal

The Settings page (package 28) gives server admins two links to `/admin/`:
**Admin** in the top bar and a separated **Server admin ↗** link at the
bottom of the Settings section nav. The owner asked on the design board
(Nov 14, 2026) to keep only the top-bar Admin link. The section nav then
lists only this page's own sections.

## Files to touch

- `src/agenticml/ui/static/app.js`: in the Settings page, stop appending
  the `settings-nav-admin` link to the nav items.
- `src/agenticml/ui/static/app.css`: remove the now unused
  `.settings-nav .settings-nav-admin` rules (desktop and the narrow-screen
  block).
- `testbed/tests/test_server_team_dashboard.py`
  (`test_settings_nav_cards_and_top_bar_by_role`): the nav links are the
  five sections only, no `/admin/` link in the nav; the top-bar Admin link
  still points to `/admin/`.
- `testbed/tests/test_server_dashboard.py`: the server-admin check asserts
  the top-bar Admin link and that the Settings nav has no Server admin
  link.
- `docs/plans/packages/28-settings-page.md`: the layout paragraph no
  longer lists the nav link.
- `docs/plans/on-prem-roadmap.md`: a 28.1 row under 28.

## Approach

1. Remove the `if (session.server_admin) navItems.push(...)` block; keep
   `navItems` (or use `links` directly) so the nav renders the same.
2. Delete the four `.settings-nav-admin` CSS rules.
3. Update the two UI tests as above.
4. Update the package 28 plan text and add the roadmap row.

## Constraints and edge cases

- The top-bar Admin link is unchanged: shown to server admins only, on
  every workspace page and on `/workspaces`.
- Non-admins saw no nav link before and see none now.
- Phone width: the nav chip row loses one chip; no horizontal page
  overflow at 375px.
- No server or API change.

## Tests and checks

- `testbed/.venv/bin/python -m pytest -q tests` from the repo root.
- `.venv/bin/python -m pytest -q -m ui` from `testbed/`.
- `git grep "settings-nav-admin\|Server admin ↗"` finds nothing in code
  or tests.

## Done when

The Settings nav shows only Account, Workspace, Members, API keys and
Activity (as the role allows), server admins still reach `/admin/` from the
top bar, and the repo and UI test suites pass.
