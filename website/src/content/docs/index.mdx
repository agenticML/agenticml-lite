The PyPI package is 1.0.0, which tracks locally only and cannot sync to the self-hosted server or the hosted service:

```bash
pip install agenticml-lite
```

Version 3.0 adds workspaces and the hosted service to the self-hosted server. It is a pre-release, so install it from GitHub (the command follows the `dev` branch and changes as development continues):

```bash
pip install 'agenticml-lite[system] @ git+https://github.com/agenticML/agenticml-lite@dev'
```

## Why agenticml-lite

<CardGrid>
	<LinkCard title="Local-first" description="Metrics, config, code, and media are written to plain files under ~/.agenticml. Nothing leaves your machine unless you sync." href="/agenticml-lite/reference/storage/" />
	<LinkCard title="Zero-code tracking" description="agenticml run train.py captures args, code, PyTorch components, and TensorBoard logs without editing your script." href="/agenticml-lite/guides/zero-code/" />
	<LinkCard title="Built-in dashboard" description="agenticml ui serves charts, media, and per-run notes on localhost, straight from the files." href="/agenticml-lite/guides/dashboard/" />
	<LinkCard title="Fast and small" description="About 3 µs per log() call and about 8 bytes per scalar point on disk." href="/agenticml-lite/reference/storage/" />
</CardGrid>
