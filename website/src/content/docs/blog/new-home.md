## New address

The documentation has moved from `agenticml.github.io/agenticml-lite/` to
[agenticml.xyz](/). Old links still work: each one redirects to the same page
at the new address, so there is nothing to update in bookmarks or READMEs. The
`agenticml ui` command and the project links on PyPI will show the new address
from the next release.

## What agenticml-lite is

agenticml-lite is local-first experiment tracking for machine learning. Runs
are plain files under `~/.agenticml` on your machine, and nothing leaves it
unless you sync. When you want a shared dashboard, you can run your own server
or use the hosted service, which is in public preview at app.agenticml.xyz.

## What this blog covers

Release notes for each new version, and how-to posts that go further than the
reference pages: tracking a real training job, running a server for a team,
and moving runs between machines.
