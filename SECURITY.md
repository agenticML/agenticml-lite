# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 3.0.x | Yes |
| 2.2.x | Security fixes until 3.1 |
| < 2.2 | No |

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub private vulnerability reporting on the [agenticML/agenticml-lite Security tab](https://github.com/agenticML/agenticml-lite/security/advisories/new). Do not open public issues or pull requests for security problems.

Please include:
- The affected `agenticml-lite` version.
- Your deployment environment (operating system, Python version, proxy).
- Step-by-step reproduction instructions or a minimal proof of concept.
- The expected behavior, actual behavior, and impact.

You will receive an acknowledgement within a few business days while the report is evaluated.

For details on security boundaries and controls, see [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
